# Runic Name

An AlterU visual experience based on Anton Bobrov's MIT-licensed
[Three.js Runic Alphabet](https://antonbobrov.github.io/threejs-runic-alphabet/).
The product mode converts the current AlterU username into a deterministic
Futhark sequence. `?baseline=1` preserves the upstream 24-glyph order.

## Dev config
node v20.2.0 \
npm v9.6.6

## Build Setup

```bash
# install dependencies
npm install

# dev mode
npm run dev

# production build
npm run build
### creates a portable static build in `dist`
```

The original source, license, and attribution are preserved in `upstream/`.
