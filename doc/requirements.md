# Runic Name 需求文档

## 1. Overview

一款 10–20 秒的 3D 身份视觉体验：玩家上下拖动自己的用户名，姓名字符会按
Elder Futhark 近似音值转写为一串由点云组成的旋转符文，抵达末端时完成一次
“封名”仪式。

## 2. Visual Design

原版黑底、白色点云符文、网格扭曲和旋转入场必须先完整保留。产品模式在顶部
安全区加入大标题 `RUNIC NAME`，底部只显示玩家原始用户名和细线进度；不加
卡片、按钮、霓虹渐变或额外粒子。符文图片是文字内容，因此由用户名决定；
`?baseline=1` 保留原作 24 个符文的固定顺序。

## 3. Game Mechanics

- 原版模式加载 24 张符文纹理，每张纹理由 150×150 分段平面上的点云采样。
- 产品模式把用户名转成 1–24 个基础符文索引；少于 12 个时重复姓名序列，
  直到 12 个，最多保留 24 个。
- 拉丁字母按 Elder Futhark 近似音值映射；`TH` 与 `NG` 优先作为二合字符。
- 无法转写的中文、数字或 Emoji 使用 Unicode code point 的稳定哈希映射到
  24 个符文，因此同一用户名始终产生同一序列。
- 拖动进度范围为 0–`glyphCount - 1`，步长 1、摩擦 0.1、轮滚速度 0.25。
- 每个符文进入窗口为 `[index-0.9,index]`，离开窗口为
  `[index,index+0.3]`；保持原作 shader 的旋转和噪声形变。
- 首次到达 100% 后，画面保持 1,100 毫秒并显示“NAME SEALED”，随后允许
  反向拖动；不会自动刷新页面。

## 4. Controls

- Touch / Pointer：单指上下拖动切换符文；同一手势的横向偏移控制轻微 3D
  视差，不阻止纵向翻页。
- Mouse：滚轮或拖动切换符文，移动鼠标控制原版视差。
- Keyboard：上下方向键每次移动一个符文；Home / End 跳到首尾。
- 不用常驻文字解释单指操作；首次进入由标准幽灵手指上下拖动，并真实推进符文。

## 5. Win / Lose Conditions

本作无失败和分数。第一次到达最后一个符文即完成一轮，结尾显示玩家用户名和
“NAME SEALED / 名字已封存”；玩家向上拖动即可回看，向下重新抵达可再次触发。

## 6. Sound Effects

- 首次真实输入后才初始化 AudioContext。
- 每跨过一个符文：190–310 Hz 三角波，45 毫秒，峰值音量 0.025，音高由
  符文索引决定。
- 抵达末端：110 Hz 与 220 Hz 两层正弦波，420 毫秒，峰值音量 0.055。
- 幽灵手指演示静音；系统静音或音频失败不影响视觉。
